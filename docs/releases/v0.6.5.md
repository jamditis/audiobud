# AudioBud v0.6.5 Windows security candidate

Status: Publication is pending protected Windows release checks.

This maintenance release keeps the WebView2 155.0.4283.62 update and the
corrected private updater verifier from v0.6.4, based on the published v0.6.0
application. Application behavior is unchanged. Windows x64 is the only
publication target; macOS publication is deferred after two CloudKit ticket
download failures in the previous candidate.

The separate maintenance branch skips the macOS job for the exact v0.6.5 tag.
The Windows build and private updater jobs are unchanged. The final job waits
for both, attests their updater evidence, attaches it to the private draft and
reads it back byte for byte. Authenticode, installer checks, SBOM, provenance,
HTTPS, updater signatures, settings/model preservation and cleanup remain
required. The live feed workflow is unchanged and still requires one successful
protected run and matching attempt.

The v0.6.1 through v0.6.4 tags and private drafts remain held or superseded.
Do not reuse their artifacts as v0.6.5 evidence. Do not merge this maintenance
branch into main, which retains the all-platform release workflow. Any later
public application release must use a version greater than 0.6.5.

Test changes reflect the Windows-only publication requirement: The macOS
workflow test retains its signing and artifact checks while expecting no macOS
dependency in the evidence publisher. The updater workflow and runbook tests
use the Windows draft step name. The release-documentation test expects 0.6.5.
No existing verification assertion is skipped or disabled.
