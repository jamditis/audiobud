# AudioBud v0.6.4 security candidate

Status: Held and superseded by the Windows-only v0.6.5 candidate. Do not publish.

Protected release run 39686205320 failed in both attempts because Apple's
CloudKit ticket download lost its connection after notarization was accepted.
The Windows build and private updater verification passed in attempt 1, but
the failed whole run does not qualify as publication evidence. Earlier tags and
private drafts remain unchanged.

This candidate retains the WebView2 155.0.4283.62 runtime refresh based on the
published v0.6.0 application. The application behavior remains unchanged. The
release verifier now imports its temporary localhost public certificate into
the machine Root store on an elevated, disposable GitHub-hosted Windows runner,
avoiding the current-user certificate consent dialog. Cleanup checks the exact
certificate thumbprint and deletes its temporary private key.

The model-preservation fixture extracts the seven named payload files from the
pinned Moonshine archive, excluding AppleDouble metadata sidecars. The archive
hash, exact file count, HTTPS, signatures, settings and model-inventory checks
remain enforced.

Earlier version tags and private drafts remain preserved. This replacement
requires signed artifacts, SBOM, provenance and updater evidence from one
successful protected workflow run and attempt before publication. Diagnostic
runs against older assets do not qualify as publication evidence.

This task publishes Windows assets. Any macOS assets staged by the joint
workflow remain excluded pending the separate platform release acceptance.
