# AudioBud v0.6.1 security candidate

Status: Local Windows candidate; publication is pending.

This patch is based on the published v0.6.0 tag. It updates the self-contained
portable installer from WebView2 150.0.4078.105 to the signed Microsoft
WebView2 155.0.4283.62 runtime, without later application changes from main.
The standard installer retains the shared Evergreen runtime.

The fixed-runtime CAB was downloaded from Microsoft's WebView2 download page.
Its Microsoft Authenticode signature and extracted browser signature are valid.
The verified CAB is 310492238 bytes with SHA-256
`cf54aa717a0ebd05b40e87620724583cb6eb0a5b8b64764cc11e42822f68bf6c`.

The workflow, portable configuration, NSIS runtime directory, and existing
download contract checks use those exact values. Existing cleanup and ACL
checks remain in place. The focused packaging suite passes seven tests.

This Windows candidate does not publish macOS, change the Microsoft Store
listing, or promote the signed updater feed. Signed release artifacts, their
SBOM and provenance, installation verification, and independent review are
pending before publication.
